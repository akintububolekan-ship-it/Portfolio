Overview

An ambient, expressive micro-state entity designed as a real-time conversational AI assistant, copilot, or wellness companion.

Project Background & Challenge

Most generative AI interfaces rely on abstract voice waves or static text bubbles, creating emotional detachment during voice interactions.

The challenge was to craft an emotive, lightweight visual anchor capable of conveying system states, focus, and empathy through minimal geometric changes and lighting dynamics.

Character Anatomy & Visual Language

Base Form: A soft-lit luminous sphere with a high-glow outer radius designed for high legibility across dark-mode surfaces.

Feature Minimalism: The face relies entirely on high-contrast vertical slit pupils to communicate attention, focus, and state changes without mouth or eyebrow complexity.

Luminescence as Feedback: Core glow and rim intensity dynamically pulse to communicate processing latency, audio gain, and device connectivity.

Motion State System Architecture

01. Default system state

02. Attention Shift - Wake-word detected

03. Cognitive Focus

04. Micro-Blink
